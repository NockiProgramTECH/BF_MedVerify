Le constat

La contrefaçon ne se voit pas. Elle se vérifie.

Une boîte peut imiter l'emballage, la marque et le prix. Ce qu'elle ne peut pas imiter, c'est un code unique, rattaché à un lot déclaré, déjà vérifié ou signalé. Encore faut-il pouvoir l'interroger.

01

L'emballage se copie

Une imprimante suffit à reproduire un blister, une notice et un numéro de lot. Sans base de référence, l'œil ne fait pas la différence.

02

Le lot disparaît

Entre l'importation, le stockage et l'officine, la traçabilité se rompt. Le patient achète alors une boîte sans historique vérifiable.

03

Le signalement arrive trop tard

Quand une boîte suspecte est repérée, l'information circule à la main. Les autres ventes du même lot ont déjà eu lieu.

Le dispositif

Un code. Un SMS. Une réponse.

Trois gestes, aucun smartphone requis, aucune connexion internet nécessaire. Le médicament parle au réseau, le réseau répond au patient.

ÉTAPE 01

Grattez la couche

Un code à 11 caractères apparaît sous la surface argentée. Il est lisible, unique et rattaché à un lot précis.

11 caractères · sans 0 ni O
ÉTAPE 02

Envoyez le SMS

Le patient recopie le code dans un message précédé de VERIF, vers le numéro court du dispositif. Aucune application, aucun forfait data.

SMS · GSM-7 · 160 caractères
ÉTAPE 03

Recevez la réponse

Le SMS revient avec le produit, le lot, l'expiration et la conduite à tenir. Quatre verdicts possibles, jamais de réponse ambiguë.

Authentique · déjà utilisé · expiré · inconnu
Le code est vérifié une première fois, puis associé à l'empreinte du téléphone — jamais au numéro en clair. Essayer le simulateur

Les réponses

Quatre verdicts. Aucune zone grise.

Chaque réponse indique quoi faire : prendre, ne pas prendre, rapporter, signaler. Le message reste court pour tenir dans un SMS unique.

VRAI · code inédit

Produit authentique

Confiance
BF-MedVerify: AUTHENTIQUE. Paracetamol 500 mg, lot BF-2291, exp 08/28. Comparez avec la boite.

Le lot existe, il est actif et le code n'avait pas encore été utilisé. Comparer reste utile : nom, dosage, lot, date.

DEJA_UTILISE · même code, autre téléphone

Déjà vérifié

Attention
BF-MedVerify: ATTENTION. Code deja verifie le 22/10. Si ce n'est pas vous, copie possible.

Une boîte scannée par un autre téléphone peut être une copie. Le message invite à ne pas la prendre et à la rapporter.

EXPIRE / REVOQUE · lot à retirer

Expiré ou rappelé

Risque
BF-MedVerify: ATTENTION. Medicament expire (06/26). Ne le prenez pas. Rapportez-le a la pharmacie.

La date est dépassée ou le lot fait l'objet d'un rappel. La Faso FDA est notifiée et peut suspendre le lot.

INCONNU · code absent de la base

Code non reconnu

Suspect
BF-MedVerify: CODE NON RECONNU. Verifiez les 11 caracteres. Si le code est exact, ne prenez pas ce produit.

Avant de conclure, le patient vérifie sa saisie. Si le code est exact, la boîte devient un signalement pour la pharmacie.

Le canal

Le SMS, parce qu'il marche partout.

Pas d'application à installer, pas de forfait data. Un téléphone à touches suffit, même dans une zone où la 3G ne passe pas.

Un alphabet sans piège

31 caractères seulement : ni 0, ni O, ni 1, ni I, ni L. Les confusions de lecture disparaissent.

Un message GSM-7, sans accent

160 caractères utiles, un seul SMS, un coût maîtrisé. Le produit, le lot et l'expiration tiennent dans la réponse.

Un anti-spam intégré

Cinq demandes par minute et par téléphone, verrouillage du code pendant la vérification : pas de test massif des codes.

Des empreintes, jamais des identités

Le code et le numéro sont transformés par HMAC-SHA256. La base ne permet pas de les reconstituer.

  • Exports prêts pour la tutelle et les partenaires.

Entrer dans le pilotage

Confiance

Le code ne dit pas qui vous êtes.

Un dispositif de santé publique ne peut pas devenir un fichier de patients. La conception retire l'identité avant même d'écrire en base.

Aucun code en clair

Seule l'empreinte HMAC-SHA256 du code est stockée. Une fuite de la base ne révèle aucun code utilisable.

Aucun numéro en clair

Le téléphone est haché avec un secret serveur distinct. Il sert à reconnaître une première vérification, pas à identifier une personne.

Un secret gardé à part

Le poivre cryptographique (BFMV_PEPPER) n'est jamais dans la base. Sans lui, les empreintes sont inexploitables.

BF7K2M9Q4XZ HMAC-SHA256 + secret a91c4e7b…c07f3e1d Le code saisi n'est jamais conservé : seule cette empreinte de 64 caractères est comparée à la base.

Poser une autre question

Faut-il un smartphone ou internet ?

Non. Un téléphone capable d'envoyer un SMS suffit. Le patient écrit le code précédé de VERIF et reçoit la réponse sur le même téléphone, même sans données mobiles.

Que se passe-t-il si le code a déjà été utilisé ?

Le message indique la date de la première vérification. Si ce n'est pas vous, la boîte peut être une copie : ne la prenez pas et rapportez-la à la pharmacie. Un même code vérifié par au moins trois téléphones différents déclenche une alerte pour la Faso FDA.

Le dispositif remplace-t-il le pharmacien ?

Non. Il ajoute une preuve au moment de la délivrance. Le pharmacien reste celui qui conseille, qui signale et qui décide de retirer une boîte du rayon.

Les numéros de téléphone sont-ils conservés ?

Jamais en clair. Seule une empreinte HMAC-SHA256 est enregistrée, avec un secret serveur. Elle sert à limiter le spam et à reconnaître une première vérification, sans identifier la personne.

Qui peut voir les données de pilotage ?

Les rôles sont séparés : la Faso FDA pilote et qualifie les alertes, les laboratoires voient leurs lots, les pharmacies voient leur officine. La maquette de pilotage détaille ces permissions.
